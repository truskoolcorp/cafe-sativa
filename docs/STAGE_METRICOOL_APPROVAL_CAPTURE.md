# Stage social approval capture

Save the approval record before publication, separately from the provider's publication receipt. This offline check makes a reconciliation binding only when a timestamped, still-pending Metricool export matches the independently reviewed post. It does not create, approve, send, retry, or reschedule posts.

1. From the authorized canary approval, prepare a JSON object with `brandId: "7605217"` and an `approvals` array. For each channel supply the exact string `postId` and `postUuid`, `network`, verbatim `caption`, `scheduledAt` and `approvedAt` (UTC whole seconds with `Z`), `mediaUrl`, SHA-256 `mediaSha256` of the reviewed asset, and an `approvalRef` identifying the durable approval record. Supply `expectedFacebookPageId` or `expectedInstagramUsername` as appropriate. Retain the signed-off record separately. Never reconstruct an approval from a provider receipt.
2. Take a fresh brand-scoped Metricool schedule export; retain its `data` array in an envelope with the actual `brandId`, `capturedAt` (UTC whole seconds), and `facebookPageId` and/or `instagramUsername` read independently from the brand settings. Do not infer the configured account from a public permalink.
3. Run `node scripts/stage-metricool-approval.cjs reviewed-manifest.json pending-brand-export.json`. Archive the successful output with the input provenance in restricted evidence storage. Use the output's `bindings` array as the trusted input to the Stage receipt reconciler proposed in #263, and keep the accompanying `audit` references. Export rejection should hold the evidence check, not trigger another submission.

The check relies on an authorized operator or audited caller for input provenance. It does not authenticate a reviewer, fetch or verify media bytes, or establish public visibility. A missing provider approval field is not a substitute for the signed-off manifest. Verify the provider receipt and public destination separately for each channel after publication. This procedure is prospective; it does not retroactively clear the November campaign's evidence gaps.
