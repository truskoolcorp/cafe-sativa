# Café publication runtime (dormant proposal)

This package composes the existing finite Café initial-standing, dispatch and positive publication-reconciliation operations. It does not enable production, install SQL, grant permissions, add a cron, buy credits, approve media or publish a post.

The authenticated GET route is deliberately unconfigured. Flags alone cannot activate it. A separately reviewed code-owned capability opener and policy are required; caller IDs, query strings and bodies are rejected.

## Execution and authority

The owner-only selector chooses stored identities, not request values. An original scheduled due attempt without confirmed positive publication evidence gets reconciliation priority. Unknown/submitting attempts hold the serial lane. A failed/missing provider observation is never success and never permits automatic retry or successor enrollment; it requires separately reviewed recovery. This conservative behavior can hold later work.

New authority candidates require current generation membership, actual hash-bound public-media QA, voice/video/publication clearance and exact existing account assignment. Private MP4 ingestion is not approval. Dispatch performs fresh canonical/media/account verification, stored publication preflight, durable claim, exact existing bearer validation, and actual provider readback. Scheduled is not published. Reconciliation stores only genuine positive destination evidence.

The runtime currently snapshots a finite semantic lease. This is suitable only for a reviewed finite run, not indefinitely recurring editorial review after lease expiry/exhaustion. Sustainable review needs a separately authorized per-occurrence lease source. It must not re-use stale authority or increase spending.

Native dispatch fetch checks both the operation flag and upstream runtime gate immediately before network I/O. Existing callers of metricoolSession retain their default fetch behavior. RPC capability openers must also enforce abort/revocation at their native transport and expose original-operation settlement.
