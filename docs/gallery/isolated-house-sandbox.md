# House Gallery sandbox acceptance — offline preparation only

This branch does not provision a Stripe sandbox, run a provider payment, or add an automatic or manual network workflow. The only CI addition is a credential-free parser/preparation self-test. Its assertions, build, and the synthetic PostgreSQL fixture are not Stripe integration evidence.

The app accepts the temporary Stripe CLI test credential only when the app and the designated database have explicit, distinct literal-loopback HTTP origins, the expected anonymous Stripe account equals the house-account configuration, the explicit local-only opt-in and existing isolated gates are on, no Vercel markers exist, and real notices are disabled. Restricted credentials may only create the approved house checkout and consume its own local Gallery payment/refund path. App code still checks account identity and readiness against Stripe's current-account response. Standard preview/test arrangements and the live credential gate are unchanged.

Review later provider execution separately:
- Use a reviewed, exact-commit, run-once isolated runner with read-only Git permissions; no default branch changes, inherited production credentials, Actions output variables carrying secrets, or fork-triggered execution. Enforce full SHA-256 asset verification before extraction and runtime. Published Linux x64 digests are pinned in tests/gallery-house-sandbox-prep.mjs; no binary has been retrieved by this change.
- Use a new temp directory and local Supabase Auth, PostgREST and Storage, a synthetic fixture seller, two synthetic buyers and a private test-art file. Verify the established loopback database and app fingerprints before starting any external test. Do not use Supabase link, db push, hosted credentials, or real project data.
- Use a new unclaimed anonymous Stripe test sandbox and official CLI only; fail if the sandbox lacks a required permission or readiness, never substitute any live or unrelated account. Receive only signed sandbox events in the local Gallery test route. Require a paid $12 house charge on the exact test account, no Connect transfer/fee, true private-file delivery to only the buyer, idempotency and signed refund plus future download denial. Existing signed links persist until their short expiry. Recording only phase-level pass/fail avoids sensitive or identifying output.
- Discard temporary keys, tokens, claim URL, raw CLI output, signed download URL, and test customer data. Never print, upload, check in, or retain provider/browser traces. Do not claim the anonymous sandbox. No production env changes or possible production payment are part of this run.
- Real Supabase local business-schema bootstrapping, Auth, Storage, listener and hosted Checkout driver are not yet executed or reviewed here. Supabase CLI and Stripe published checksums come from the [Stripe release assets](https://github.com/stripe/stripe-cli/releases/expanded_assets/v1.55.14) and [Supabase release assets](https://github.com/supabase/cli/releases/expanded_assets/v3.3.0).
