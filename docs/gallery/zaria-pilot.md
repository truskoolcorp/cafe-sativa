# Gallery curator pilot

Zaria alone has independent, default-off Gallery switches. No other host, Stage, inventory or payment deployment is required.

- `CS_ZARIA_GALLERY_PORTRAIT`: allow the named Gallery host portrait only after GLYPH confirms the exact locked rights-approved primary and checksum. Serve a resized 448×560 PNG derivative; never publish the source image or admin endpoint. On failure show an unavailable message and keep browsing.
- `NEXT_PUBLIC_CS_ZARIA_GALLERY_CHAT`: add Gallery/artwork links and Zaria in /ask, and admit only the existing web-chat endpoint for this host. Public-view-only catalog reads bind the selected slug and supply genuinely available browse routes, not guesses. Do not claim purchases, dates, inventory or artwork availability based on missing/untrusted records.
- `CS_ZARIA_GALLERY_LIVE_VOICE`: keep **off**. The exact `cafe-sativa-zaria` worker, canonical Bree ID, and Eleven v4 attestations are required in addition to existing site voice settings. Signed-in visitors must first have their own Zaria conversation; stop, mic-only grants and no persona fallback apply. Legacy public TTS doesn't admit Zaria.

The checked-in shared voice worker explicitly allows only the existing three hosts, targets production memory, and uses the single-voice ElevenLabs TTS plugin default. Do not repurpose it or relax its allowlist here. ElevenLabs documents that [the standard TTS WebSocket does not support Eleven v4](https://elevenlabs.io/docs/eleven-api/guides/how-to/websockets/realtime-tts); a separate v4 [Text-to-Dialogue WebSocket](https://elevenlabs.io/docs/eleven-api/guides/how-to/websockets/tts-vs-ttd-websockets) adapter/agent and verified private memory endpoint are prerequisites. Never substitute a model or voice. Do not set the attestation flags based on source inspection alone.

Private demo (no charges or production writes as part of this draft): absent flags show no new portrait/chat or mic; portrait flag renders the derivative or explicit fallback. With chat enabled on an authorized private environment, ask about a selected work, request an alternate/next stop, verify the real live empty state, use unrelated/private/NFT slug to verify refusal, and exercise desktop/mobile keyboard controls. Before any voice flag, separately verify exactly Bree/v4, private memory origin, session ownership, barge-in/stop and same catalog context. Disabling the Zaria voice flag closes the site bridge; keep public caption/text fallback. Future hosts should conform to this verified grounding and navigation contract without inheriting Zaria’s specific catalog or flags.
