# Isolated persona browser check

The PR-triggered workflow builds a self-contained fixture from the checked-out review panel, workspace, dispatch confirmation and time utilities. No copied application component bundle is committed. Source hashes and the tested GitHub SHA accompany screenshots and assertions.

Official Playwright 1.56.1 and its Chromium are installed in a runner-temporary prefix, leaving the application lockfile unchanged. Existing locked TypeScript, React and Tailwind dependencies build the fixture. No application server, database, deployment environment, provider or secrets are used. Browser requests are aborted, service workers are blocked and the fixture CSP forbids connections. Only allowlisted synthetic fetch responses are returned; unexpected URLs/methods fail. Mock POSTs exercise uncertainty, explicitly released pending responses and matching success receipts. None performs an external action.

Coverage: keyboard consent and submit; no automatic retry after uncertainty; pending double-submit lock; matching synthetic scheduled receipt (not publication); rollout-disabled and fractional-time guards; explicit whole-second authoring; missing-time and uncertain-edit controls; read-only evidence display; actual Workspace acknowledgement/video confirmation, explicit QA observation, withdrawal review/save and restoration; mocked attempt-state reload suppressing dispatch; desktop screenshots and 375px viewport overflow. Failures retain diagnostics; no test retries are configured.

This is a synthetic component smoke gate, not a live integration or content approval. It does not exercise real provider receipts, actual media playback, database durability after reload, authenticated server routes, all eight QA decisions or provider transmission. Successful Workspace actions and attempt-state reload are simulated only, not database proof. Existing unit and PostgreSQL jobs remain required. Hosted browser assertions are unverified until this workflow actually runs; local build/type checks are not browser execution.
